# 三分钟活动实验室

高校 LifeHack 生活娱乐赛道的网页应用。面向社团负责人、班委和小型聚会组织者，在约三分钟内完成「设定活动 → 挑选环节 → 应对突发状况 → 获取执行方案」。基本流程离线可用；DeepSeek 推荐需要网络与 API Key。

## 启动

建议使用 Node.js 24（本项目已用 24.18.1 验证）。

```bash
npm install
npm run dev
```

运行测试与构建：

```bash
npm test
npm run build
```

生产构建后，在本机启动含 AI 代理的服务：

```bash
npm run start
```

## 启用 DeepSeek 推荐

在网页右上角打开「设置」，填入自己的 DeepSeek API Key 并保存，然后在挑选环节页点击「要不问问AI？」进入聊天。可以多轮补充偏好；AI 提出可执行环节后，点击「确认采用，更新当前方案」才会写入选择。也可以将 `.env.example` 复制为 `.env.local`，填写 `DEEPSEEK_API_KEY=` 后重启服务。不要将 `.env.local` 提交到 GitHub，也不要把密钥发到聊天中。

网页只调用同源 `/api/ai/recommend`；本机 Node 服务向 DeepSeek 的 Chat Completions 接口发送请求，使用 `deepseek-flash` 与 JSON 输出。页面设置的 Key 仅保存在当前浏览器的 localStorage，请勿在共享电脑上保存；请求时经同源本机服务转发，不写入前端构建文件。`.env.local` 的服务端 Key 可作为备用。服务默认只监听 `127.0.0.1:8787`。Vite 将 `/api` 转发给本机服务。未配置密钥时，手动策划保持可用。AI 建议只会从本地活动库中选 1–2 项，采用前再次校验人数、场地、时间与预算。启用后会消耗你的 DeepSeek API 额度。

## 规则与数据

- `src/data/activities.ts` 包含 25 个结构化活动环节；常规推荐先按活动类型、人数、场地、单项预算和时长筛选，再按估算材料费和时长排序，展示最多三项。AI 可在全部可行候选中挑选，组合仍需通过本地规则校验。
- 每场固定预留 10 分钟开场和 10 分钟收尾。环节时长相加若超过设定时长，页面阻止生成。
- 材料按同名合并。固定数量与按人数估算数量相加；共享物资取最大需求量。总额为数量乘单价之和，精确到分。价格为演示估算，组织者应按当地价格调整。
- 突发状况由明确规则调整人数、场地或预算，并重新计算物资和适配环节。结果页可手动修改数量与单价。
- 最近方案、制定记录和收藏保存在当前浏览器的 localStorage；不上传到服务器，也不跨设备同步。历史旧方案会自动进入记录。可从顶部打开记录或清除本地数据。
- AI 只选择现有可行环节并提供简短建议。预算、人数、场地和流程计算始终由本地确定性规则负责。AI 建议采用后会写入当前方案及其记录，复制全文时也包含建议。

## 导出与后续 Windows EXE

结果页支持复制全文，或使用浏览器打印功能选择「另存为 PDF」。网页稳定后可安装 Tauri 2 CLI，配置 `beforeDevCommand` 为 `npm run dev`、`beforeBuildCommand` 为 `npm run build`、`frontendDist` 为 `../dist`，再用 `tauri build` 生成 Windows 安装包。打包时需要把本机 AI 服务改为 Tauri 侧命令或受控 sidecar；不能把 API Key 放到前端资源中。打包前需安装官方要求的 Rust 与 Windows 构建依赖，并在 Windows 上测试本地存储、打印和剪贴板功能。

## 当前限制

活动库是离线精选内容，费用按统一示例价格估算，不包含场租与交通费；不会联网查询实时价格。AI 功能需自行配置密钥，当前环境没有密钥，尚未验证真实 DeepSeek 响应。分享靠复制或打印，不提供多人实时协作。
