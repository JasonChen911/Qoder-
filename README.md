# 三分钟活动实验室

高校 LifeHack 生活娱乐赛道的离线网页应用。面向社团负责人、班委和小型聚会组织者，在约三分钟内完成「设定活动 → 挑选环节 → 应对突发状况 → 获取执行方案」。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

运行测试与构建：

```bash
npm test
npm run build
```

## 规则与数据

- `src/data/activities.ts` 包含 25 个结构化活动环节；推荐按活动类型、人数与场地筛选，再按估算材料费和时长排序。展示最多三项。
- 每场固定预留 10 分钟开场和 10 分钟收尾。环节时长相加若超过设定时长，页面阻止生成。
- 材料按同名合并。固定数量与按人数估算数量相加；共享物资取最大需求量。总额为数量乘单价之和，精确到分。价格为演示估算，组织者应按当地价格调整。
- 突发状况由明确规则调整人数、场地或预算，并重新计算物资和适配环节。结果页可手动修改数量与单价。
- 最近方案和收藏保存在当前浏览器的 localStorage；不上传到服务器。可从顶部清除。
- 当前版本不使用 AI 服务。未来可在独立服务层增加标题、文案、创意润色；预算和流程规则继续保持确定性。

## 导出与后续 Windows EXE

结果页支持复制全文，或使用浏览器打印功能选择「另存为 PDF」。网页稳定后可安装 Tauri 2 CLI，配置 `beforeDevCommand` 为 `npm run dev`、`beforeBuildCommand` 为 `npm run build`、`frontendDist` 为 `../dist`，再用 `tauri build` 生成 Windows 安装包。打包前需安装官方要求的 Rust 与 Windows 构建依赖，并在 Windows 上测试本地存储、打印和剪贴板功能。

## 当前限制

活动库是离线精选内容，费用按统一示例价格估算，不包含场租与交通费；不会联网查询实时价格。分享靠复制或打印，不提供多人实时协作。
